About this site

A growing collection of free, private browser tools.

What this is

ToolNest started as a single QR code scanner and generator. It is now expanding into a collection of small, useful utilities for text, files, images, PDFs and code.

What makes it different

  • Runs in your browser. Every tool works locally on your device. Nothing is uploaded to a server.
  • No accounts. No signup, no email, no password.
  • No tracking beyond anonymous analytics. We do not sell data.
  • Fast. Static pages, no server round-trips, works offline after first visit.

How it works

All tools are built with plain HTML, CSS and JavaScript. There is no backend. Where heavier processing is needed — PDF handling, image manipulation, video conversion — we use client-side WebAssembly libraries that run inside your browser tab.

Feedback

Found a bug? Want a tool that isn’t here yet? We’d like to hear about it. Reach out through the QR Scanner page footer.
