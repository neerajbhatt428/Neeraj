About this site

A growing collection of free, private browser tools — built for people who don't want to upload their files to a stranger's server just to resize an image.

What LocalTools is

LocalTools is a collection of small, focused utilities that run entirely inside your web browser. Resize an image, merge two PDFs, format JSON, convert units, scan a QR code, count the words in a draft — the kind of everyday task you'd normally open a website for, upload a file to a server you don't control, and hope for the best.

Here, nothing gets uploaded. The tools load once and then work on your own device, using the same CPU and memory you'd use to open the file locally. Your tax return, your ID scan, your client's contract — none of it leaves your machine.

Why it exists

Most online tools do the same thing: they ask you to upload your file to a server, they process it for a few seconds, and they send back a download link. For some tasks, that's fine. For others, it's a problem:

  • You're on a slow connection and uploading a 40 MB PDF takes longer than the work itself.
  • You're handling a document you can't legally send to a third-party server — a contract, a medical record, an ID card.
  • You're on a shared computer and don't want your data sitting in a stranger's cloud.
  • The tool you found has a three-file-per-day limit unless you pay $12/month.
  • The tool went offline last year and you have no idea where your files went.

LocalTools is the answer to those. Everything runs on your side. There's nothing to sign up for, nothing to pay for, and nothing to trust beyond the code already loaded in your browser.

What makes it different

  • Runs in your browser. Every tool works locally on your device. Files are read, modified and saved without ever touching a server.
  • No accounts. No signup, no email, no password. Open a tool and use it.
  • No uploads. Not even for PDF or video tools. Everything is client-side, including the heavy processing that would normally require a backend.
  • No watermarks. Output files are clean. Nothing branded, nothing added.
  • No usage limits. Process one file or a hundred. The only ceiling is what your device can handle.
  • Works offline. After the first visit, most tools keep working without an internet connection — because nothing needs the network to function.
  • No tracking beyond anonymous analytics. We don't sell data. We don't build profiles. We don't know who you are.

How it works

Every tool is a single HTML page with plain JavaScript. There's no backend, no database, no API. The site is served as static files.

Where heavy processing is needed, we use libraries compiled to WebAssembly that run inside your browser tab:

  • PDF tools use pdf-lib for reading, splitting, merging and re-saving PDFs, and pdf.js for rendering pages to screen. Every byte stays on your device.
  • Image tools use the Canvas API for resizing, cropping and format conversion.
  • AI features like background removal run small neural networks locally using ONNX Runtime Web. The model downloads once, then runs entirely on your CPU or GPU.
  • QR scanning uses the device camera and a JavaScript decoder — the video frame is never transmitted anywhere.

This architecture means the site is fast, cheap to run, and cannot leak your data even if it wanted to.

A short history

  • The original QR scanner LocalTools started as a single free QR code scanner at qrcodescanner.co.in — a small tool built because every existing QR scanner wanted camera permissions, showed ads before the first scan, and uploaded every decoded code to a tracking server.
  • Growing into a collection Once the QR scanner worked, the same principle applied to other everyday tasks. Word counters, image compressors, PDF editors — all built the same way: plain HTML, plain JavaScript, no server.
  • The move to LocalTools As the toolset grew past 30 utilities, the old "QRCodeScanner" name no longer fit. The site moved to localtools.co.in and the tools were organised into categories — text, image, PDF, developer, calculators, security and generators.
  • Where it's headed The goal is simple: every tool a person needs in a typical week, running in the browser, free, private, and fast. No app to install, no account to keep, no subscription to cancel.

What it isn't

To set expectations honestly:

  • It's not a replacement for professional software. The PDF editor is good for annotations, signing and light edits — it's not Adobe Acrobat for full document workflows.
  • It can't do everything. Anything that needs a server — sending email, processing payments, running a database, fetching live currency rates — is out of scope by design.
  • It's not for password cracking. Tools like the PDF unlocker remove your own passwords and permissions. They cannot and will not brute-force a forgotten password.
  • Very large files can be slow. Processing runs on your device, so a 500 MB video will take longer here than on a machine with a dedicated GPU. On modern hardware, this is rarely noticeable.
