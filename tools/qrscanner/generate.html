What each QR code type does

URL / Text

Paste a website address, or type any short piece of text. When someone scans it, their phone opens the link or shows the text.

Wi-Fi

Enter the network name (SSID), the password and the security type. Guests scan the code and their phone joins the network without typing the password. Useful for cafés, offices, guest rooms and home routers.

Phone

Encodes a phone number. Scanning it opens the dialer with the number ready to call.

Email

Opens a new message to the recipient, with an optional subject and body pre-filled.

SMS

Opens a new SMS to a phone number with a pre-filled message.

UPI

Encodes a UPI payment request. Include the UPI ID, payee name, optional amount and note. When scanned, supported apps open the payment screen. Always verify the details before completing a payment.

Contact

Creates a vCard. Scanning it lets the recipient add you to their contacts with name, phone, email and company.

Choosing size and error correction

Size is the pixel dimension of the PNG. 240×240 is fine for on-screen use. Print at 400 or 500 for posters, business cards or stickers. Bigger images are easier to scan.

Error correction controls how much of the code can be damaged before it stops working:

  • Low (7%) — smallest pattern. Best for digital-only use with high contrast.
  • Medium (15%) — the default. Good balance for most uses.
  • Quartile (25%) — useful for logos or slightly busy backgrounds.
  • High (30%) — best for printed codes on packaging or outdoors.

Higher error correction makes the pattern denser, which means the code needs to be printed at a slightly bigger size to stay easy to scan.

Custom colors

You can set the foreground and background colors. Two rules to keep the code scannable:

  • Keep strong contrast. Dark on light works best. Very light foreground on a slightly lighter background usually fails.
  • Do not invert the pattern. A light code on a dark background is harder for many scanners to read.

Common questions

Is the QR code generator free?

Yes. It is completely free, has no watermark and no account is required.

Do the QR codes expire?

No. These are static QR codes — the data is stored directly in the pattern, so they never expire.

Can I change the colors?

Yes. Keep strong contrast between the foreground and background so scanners can still read the code.

What is error correction?

It sets how much of the code can be lost before it becomes unreadable. Higher levels survive more damage but make the pattern denser.

Can I make a Wi-Fi QR code?

Yes. Choose Wi-Fi, enter the network name, password and security type. Guests scan to join.

Can I make a UPI QR code?

Yes. Choose UPI, enter the UPI ID and optional name, amount and note. Always verify payment details before sending money.
