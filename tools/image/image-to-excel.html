    How to convert an image to Excel

    1. Drop the image. Screenshots, photos or scans. Multiple images become multiple sheets.
    2. Wait a moment. OCR runs automatically — you'll see the result in a few seconds.
    3. Check the confidence badge. Green means it looks good. Yellow means review a few cells. Red means try a different attempt.
    4. Try a different attempt if needed. Four OCR passes run in the background. Click any to preview it.
    5. Fix any cells. Click, type, Tab, Enter, arrow keys — just like Excel. Right-click for row/column operations.
    6. Export. XLSX for a formatted workbook, or CSV / JSON / TSV.

    Why it works on hard images

    Most image-to-Excel tools try one approach and hope it works. This tool runs four different OCR passes and scores each on cell density, confidence and grid regularity, then presents the best one. You can switch to any of the others if the automatic choice is wrong.

    • Dark tables — polarity detection inverts before OCR.
    • Alternating row colours — adaptive threshold normalises them.
    • Watermarks — filtered out by word-height analysis.
    • UI dropdown arrows — stripped from header cells.
    • Numbers with commas — cleaned so Excel treats them as numbers.

    Common questions

    Is it free?

    Yes. No signup, no watermark, no page limit.

    Are my images uploaded?

    No. Everything runs in your browser using Tesseract.js. Your images never leave your device.

    Why multiple OCR attempts?

    Different images need different preprocessing. Instead of guessing, the tool tries several and shows the best result — you can pick a different one with one click.

    What about handwriting?

    Tesseract is designed for printed text. Handwriting will not convert reliably — no free browser tool handles it well.

    Can I edit the result?

    Yes. Click any cell, use arrow keys, Tab, Enter. Right-click for insert/delete row or column.
