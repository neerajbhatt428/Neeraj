    How to convert an image to Excel

    1. Upload the images. Drop up to 20 files, or click to choose. Each becomes a separate sheet in the workbook.
    2. Pick the language and leave Auto-invert dark enabled if your tables have dark headers or dark themes.
    3. Convert. The tool detects table borders, extracts text from each cell, and assembles a grid.
    4. Review the overlay in the Image tab. Red lines mark detected rows, blue lines mark columns.
    5. Fix any mistakes. Click a cell, type, or paste from the clipboard. Tab and arrow keys move like Excel.
    6. Export. Multi-sheet XLSX, CSV, JSON or TSV.

    What it handles well

    • Dark-themed tables — dark headers, alternating row colors, light text on dark backgrounds. The tool inverts these automatically.
    • Excel and Google Sheets screenshots — near-perfect accuracy.
    • Styled tables with bold headers — grid line detection finds the actual borders.
    • Numbers with commas and decimals — cleaned up and left as numbers so Excel treats them as numbers.
    • Watermarks — filtered out as low-confidence noise when they overlay cell content.
    • Filter dropdown arrows (▼ ▾) — stripped from header cells.

    How the detection works

    The tool runs a five-stage pipeline on every image:

    1. Polarity detection. A histogram analysis using Otsu's method determines whether the image is dark-on-light or light-on-dark. If dark-on-light, it inverts.
    2. Grid detection. A projection profile of the luminance across each row and column finds sharp transitions, which correspond to table borders. This gives exact cell coordinates.
    3. OCR. Tesseract extracts every word with its bounding box.
    4. Cell assignment. Each word is assigned to the cell whose bounds contain it. If grid detection failed, falls back to clustering by word positions.
    5. Cleanup. Numbers with OCR artifacts (spaces inside numbers, stray characters) are corrected. Watermark noise and dropdown arrows are filtered.

    Why this handles dark tables

    Tesseract is trained on dark text on light backgrounds. The typical failure mode on a dark table is that OCR returns garbage or nothing at all. This tool detects dark themes automatically and inverts them before OCR, so dark headers and alternating row stripes don't confuse the engine.

    Common questions

    Is this tool free?

    Yes. Completely free, no signup, no watermarks and no page limit.

    Are my images uploaded?

    No. OCR runs entirely in your browser using Tesseract.js. Your images never leave your device.

    Does it handle dark tables?

    Yes. The tool detects light-on-dark polarity automatically and inverts before OCR.

    How accurate is the OCR?

    Clear screenshots convert with 95%+ accuracy. Photos need good lighting and focus. Handwritten text will not convert reliably.

    Can I edit the result before downloading?

    Yes. The table is fully editable — click any cell, use arrow keys, Tab, Enter, Delete. Right-click for row/column operations.

    What if the detection fails on my image?

    Try turning off Auto-invert if the table is already light-themed, or toggle Detect grid lines. For photos, enable Auto-enhance and Upscale 2×.
