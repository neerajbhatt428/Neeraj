How to use the image resizer

Drop images onto the page or click to browse. Choose how you want to resize — exact pixels, a percentage, or a preset — and everything updates as you type. Each image is resized independently. Download them one at a time, or all together as a ZIP.

Nothing is uploaded. Everything happens on your device using the browser's Canvas API.

Three resize modes

Exact pixels

Enter a specific width and height. With Lock aspect ratio on, changing one dimension updates the other to match the original image's proportions. Turn it off to force an exact size — useful for avatars that must be square.

Percentage

Scale the image up or down by a percentage. 50% halves both dimensions. 200% doubles them. Simple when you just want "half the size."

Lock aspect ratio

When on, entering a new width automatically adjusts height to keep the original proportions. When off, you can stretch or squash — usually a bad idea for photos, but sometimes needed for fixed-size slots.

Don't enlarge small images

If you set a width larger than the original, some tools upscale by inventing pixels — which looks blurry. Turn this on to leave images smaller than the target untouched. Or leave it off to force the target size.

Resize vs compress

Resizing changes the pixel dimensions. Compressing reduces file size by lowering quality. They're independent — you can resize without changing quality, or compress without resizing. Often you want both: resize to the display size, then compress lightly. Use the Image Compressor for the compression step.

Common questions

Is this image resizer free?

Yes. It is free, has no file size limit and runs entirely in your browser.

Are my images uploaded?

No. Everything happens on your device. Your images never leave your computer or phone.

What is the difference between resizing and compressing?

Resizing changes the pixel dimensions. Compressing reduces file size by lowering quality while keeping the same dimensions. Often you want both.

Can I resize multiple images at once?

Yes. Drop as many as you like. Each is resized to the same target and you can download them all in one ZIP.

Will resizing reduce image quality?

Downsizing usually improves apparent sharpness because you're discarding pixels the screen can't display anyway. Upsizing always softens an image. Stick to downsizing when possible.

What happens to PNG transparency when I convert to JPG?

JPG doesn't support transparency. Any transparent areas become the background color you choose (white by default). Keep PNG or WebP if you need transparency preserved.

Does it work on iPhone photos?

Yes. HEIC files are not directly supported by all browsers, so if you're on iPhone you may need to convert to JPG first — iOS does this automatically when sharing to most apps.

Is there a file size limit?

No hard limit, but very large files (50 MB+) may be slow on low-end devices because processing happens in memory.
