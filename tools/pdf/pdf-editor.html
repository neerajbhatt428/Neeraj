      How to use the PDF editor

      1. Drop a PDF onto the viewer, or click Choose PDF.
      2. To edit existing text: click the Edit text tool, then click any word or number. Type the replacement and press Enter.
      3. To add new text: use the Add text tool and click anywhere.
      4. To highlight, draw, redact or add notes: pick a tool and drag on the page.
      5. To insert an image or signature: click the tool, then click to place.
      6. To select and adjust anything: switch to the Select tool and click the element. Drag to move, drag corner handles to resize.
      7. Use Ctrl+scroll or the + / − buttons to zoom.
      8. Click Save edited PDF to download.

      What you can do

      • Edit existing text — click a word, type a replacement. Perfect for invoices, forms and dates.
      • Add text with 7 fonts and any color
      • Highlight — translucent rectangle in any color
      • Rectangles and arrows for emphasis and callouts
      • Sticky notes — yellow boxes with wrapped text
      • Redact — solid black boxes
      • Images and signatures — drop them anywhere
      • Page operations — reorder, rotate, delete
      • Select any element to move, resize, change color, font, size or text

      Sharp text at every zoom level

      Pages render at devicePixelRatio × zoom, so text on screen matches a native PDF reader. Zoom from 25% to 600% with the toolbar, Ctrl+scroll, or keyboard shortcuts.

      Vector output — original text stays selectable

      The original PDF pages are copied byte-for-byte into the output. Original text remains selectable and searchable, and your additions become real vector text.

      Keyboard shortcuts

      • Delete — remove selected element
      • Ctrl+Z — undo
      • Esc — deselect / cancel
      • Arrow keys — nudge selected element 1px (Shift for 10px)
      • Ctrl+=, Ctrl+−, Ctrl+0 — zoom in, zoom out, fit

      Common questions

      Can I edit existing text in the PDF?

      Yes. Click the Edit text tool, then click any word or number. The tool detects the original text, covers it, and draws your replacement in the same position and style.

      Does the editor upload my PDF?

      No. Your PDF is read, modified and re-saved entirely inside your browser.

      Will the original text stay selectable?

      Yes. Original pages are copied byte-for-byte into the output, so selectable text is preserved. Your additions are real vector text too.

      Can I select and move an element after placing it?

      Yes. Click any element with the Select tool, drag to move it, drag corner handles to resize, double-click to edit text content.

      Can I sign a PDF?

      Yes. Click Sign, draw your signature, then click on the page to place it. Move, resize and re-color it after placing.
