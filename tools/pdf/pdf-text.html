Extract text from any PDF — free, in your browser

This tool pulls all the text out of a PDF and gives it to you as plain, copyable text. Drop a file, click Extract, and you get the full document in one place — searchable, copyable, and downloadable as a .txt file. Everything runs locally in your browser using JavaScript, so contracts, tax documents, medical records and legal filings never leave your device.

Unlike most online PDF text extractors that upload your file to a server, keep it for hours, or require an account, this tool reads the PDF into memory on your machine, extracts the embedded text layer, and gives you the result. You can disconnect from the internet after the page loads and keep extracting.

How to extract text from a PDF

  1. Open the PDF. Drop a file onto the drop zone or click to browse. Page count and file size display automatically.
  2. Choose extraction mode. Preserve line breaks is the safest default for most documents. Merge into paragraphs is better for prose. Raw keeps all original spacing intact.
  3. Select pages (optional). Extract from all pages, or type a range like 1-3, 5, 8-12 to focus on specific sections.
  4. Extract the text. Click Extract text. A progress bar shows which page is being read.
  5. Review, search, copy. Switch between Combined view (all pages together) and By page view (a separate block for each page). Use the search box to find specific terms — matches are highlighted with a live count.
  6. Copy or download. Click Copy all text to paste into another app, or Download as .txt to save a plain UTF-8 text file.

The three extraction modes

The right mode depends on what you'll do with the text:

How the extraction works

PDFs are not text documents — they're layered instructions. Each glyph is placed at an exact XY coordinate on the page. To extract readable text, the tool:

  1. Loads the PDF using Mozilla's pdf.js — the same library Firefox uses to display PDFs.
  2. Asks each page for its text layer, which returns individual text fragments and their coordinates.
  3. Sorts the fragments top-to-bottom then left-to-right so lines come out in reading order.
  4. Groups fragments that share the same Y coordinate into lines.
  5. Applies the mode you chose (line breaks, paragraphs, or raw).

Text is extracted exactly as the PDF stored it. Fonts, bold, italic, colour and layout are not preserved because PDFs don't store them as styled runs — they store glyphs at coordinates. The result is the same text a PDF reader would give you if you selected it and copied.

When extraction fails — and why

If the output is empty, gibberish, or full of symbols, the PDF is likely one of these:

  • Scanned document. Scans are images of pages, not text. There's no text layer to extract. You need OCR (Optical Character Recognition) — a separate process that reads pixels and guesses the letters.
  • Custom font encoding. Some PDFs use non-standard character mappings, usually for copyright or styling reasons. The text extracts as symbols or wrong characters. This is a property of the PDF itself; no extractor can fix it.
  • Password-protected. If the PDF requires a password to open, remove it first with a tool like qpdf.
  • Corrupted file. If a PDF opens in a reader but fails here, try re-downloading or re-exporting it.

Common uses

  • Copy quotes from a paper or report. Extract the text, search for the passage, copy it directly.
  • Search inside a long PDF. Extraction puts all text in one scrollable block that your browser's Ctrl+F can search instantly.
  • Translate a document. Extract the text, then paste it into DeepL, Google Translate or any other service.
  • Reuse content. Move PDF text into a Word document, note app or email without retyping.
  • Screen-reader accessibility. Copy the text into an app that reads it aloud.
  • Feed text into another tool. Extract, then run through a word counter, keyword density checker, or diff checker.
  • Legal and compliance. Pull specific clauses, definitions or disclaimers out of contracts for comparison.
  • Academic research. Extract abstracts, bibliographies or citation data from papers.
  • Data entry. Pull invoice numbers, order IDs or serial numbers out of PDFs into a spreadsheet.
  • Archive cleanup. Convert old PDFs to plain text for long-term readability, since .txt files remain openable on any device forever.

Your privacy is protected

Every operation happens in your browser. The PDF is read into memory, its text layer is extracted, and the result is displayed or saved by your own device. No PDF is ever sent to any server, logged, or retained.

The only network request the page makes is for Mozilla's pdf.js library, loaded from a public CDN when the page first opens. After that, the tool works entirely offline. You can disconnect from the internet and keep extracting text.

This makes the tool safe for documents you'd never upload to a cloud service: contracts, medical records, tax returns, bank statements, legal filings, signed agreements, internal reports.

What this tool can't do

Being honest about limits is more useful than pretending they don't exist. This tool does not:

  • OCR scanned PDFs. If the PDF is a scan, there's no text to extract. You need an OCR tool (Tesseract, Adobe Acrobat Pro, or an online OCR service).
  • Preserve formatting. Fonts, bold, italic, colour, tables and column layouts are not preserved. Only the text content.
  • Extract images, charts or diagrams. Only the text layer is read. To capture visuals, use PDF to Image.
  • Extract from password-protected PDFs. If a password is required to open the file, remove it first with a tool like qpdf.
  • Handle multi-column layouts cleanly. Two-column pages may interleave text because the PDF stores glyphs by coordinate, not by column. Try the Raw mode, or extract page by page.
  • Edit the PDF. Use PDF Editor to change text, add annotations or sign pages.
  • Convert to Word or HTML. The output is plain text. To preserve formatting, use a dedicated PDF-to-Word converter.
  • Handle very large PDFs fast. A 500-page PDF takes 30–60 seconds to extract. The progress bar shows how far along it is.

Troubleshooting

  • "PDF.js library not loaded" — the CDN is blocked or you're offline before the first page load. Refresh the page once. After that, the tool works offline.
  • Extracted text is empty — the PDF is a scan and has no text layer. You need OCR.
  • Extracted text is gibberish — the PDF uses custom character encoding. No extractor can read it without the font's mapping.
  • Words run together without spaces — try the Raw mode, or extract one page at a time. Multi-column PDFs often separate words because PDFs store them as separate glyphs.
  • Text appears in wrong order — some PDFs store text in non-reading order (like posters). The tool sorts by Y then X, which works for most documents but not all.
  • Search finds no matches — the search is case-insensitive but literal. Try shorter search terms. Special characters like . or $ are treated as literals, not regex.
  • Copy button does nothing — some browsers block clipboard access on non-HTTPS pages. The download option always works.
  • Very large PDF takes forever — extraction is single-threaded. Close other tabs. On desktop, 500 pages takes about 30–60 seconds.

Common questions

Can I copy text from a scanned PDF?

Only if the PDF contains a text layer. Scanned PDFs are usually images, so they contain no extractable text. You would need OCR to read them.

Is my PDF uploaded?

No. Everything happens in your browser. Your files never leave your device.

Can I download the extracted text?

Yes. Click Download as .txt to save all extracted text to a plain text file.

Does it preserve formatting?

It preserves line breaks and text order, but not fonts, bold, italics, or tables. PDFs store layout as drawing instructions, not as styled text.

Can I extract just one page?

Yes. Choose Custom range under Pages and enter the page number, e.g. 5 or 1-3.

How accurate is the extraction?

Very accurate for text-based PDFs. The output matches what a PDF reader sees when you select and copy text.

What about PDFs with multiple columns?

Text is extracted in reading order as the PDF stores it. For two-column layouts, the output may interleave. Use Raw mode or copy page by page for cleaner results.

Does it work on password-protected PDFs?

Not if the PDF requires a password to open. If the password is only for editing, extraction usually works.

What is the difference between the three extraction modes?

Preserve line breaks keeps each PDF line on its own line. Merge into paragraphs joins lines that belong to the same paragraph. Raw keeps all original spacing intact.

Can I search inside the extracted text?

Yes. The search box highlights every match in the output, showing a live count of how many times the term appears.

What file formats can I save the text to?

Plain text (.txt) with UTF-8 encoding. This opens correctly in any text editor, word processor or spreadsheet.

Does it work on iPhone and iPad?

Yes. It runs in Safari on iOS and Chrome on Android. Tap the drop zone to select a PDF from Files or Downloads.

Will it extract images or tables?

No. Only the embedded text layer is extracted. Images, charts, tables, form fields and annotations are not read. To capture those, use PDF to Image and process the pages separately.

Does it work offline?

Yes. After the page loads once, the tool works entirely offline. Disconnect from the internet and keep extracting text.

How is this different from Adobe Acrobat?

For text extraction, nothing — it does the same job. Acrobat offers advanced features like OCR and form creation, but for pulling plain text out of a text-based PDF this tool matches it for free and without uploading.
