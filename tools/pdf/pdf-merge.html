Merge PDFs in your browser — no upload, no watermark

This is a free PDF merger that combines two or more PDF files into a single document without uploading anything. Everything happens locally in your browser using JavaScript, so your contracts, invoices, tax documents, medical records and ID scans never leave your device.

Unlike most online PDF mergers that upload your files to a server, keep them for hours, watermark the output, or require an account, this tool loads the PDFs into memory on your machine, combines them, and gives you a downloadable file. You can disconnect from the internet after the page loads and keep using it.

How to merge PDFs

  1. Add your files. Drop two or more PDFs onto the drop zone, or tap the box to browse. Each file is read into your browser's memory only.
  2. Check the list. Every file shows its filename, page count and size. Files that fail to open are marked in red with the reason.
  3. Set the order. Drag the handle on the left of each row on desktop. On mobile, tap the ↑ and ↓ buttons. The order in the list is the order of pages in the output.
  4. Merge. Click Merge PDFs. A progress bar shows how far along the merge is.
  5. Download. Click Download merged PDF. The file is saved with a date-based name like merged-2026-10-12.pdf.

What makes this merger different

  • Nothing is uploaded. Your files stay on your device. No server, no retention policy, no third-party access.
  • No watermarks. The output is a clean PDF with only your content.
  • No account, no limits. No signup, no email verification, no daily quota.
  • Preserves quality. Pages are copied byte-for-byte. Fonts, images, vector graphics, links and bookmarks all carry through unchanged.
  • Drag-and-drop reordering. Move files up or down to control page order.
  • Reverse in one click. If you've added files in reverse order, one button flips everything.
  • Works on mobile. iPhone and Android browsers handle the whole workflow, including reordering via arrow buttons.

How the merge works

The tool uses pdf-lib, an open-source JavaScript library that runs in your browser. When you click Merge PDFs, it:

  1. Loads each PDF into memory as a structured object.
  2. Creates a new empty PDF document.
  3. Copies every page from each source file into the new document, in the order you set.
  4. Adjusts internal references — bookmarks, form fields, annotations — to account for the pages added before their source.
  5. Serialises the result into a single PDF and hands you a download link.

Original pages are copied as-is. There is no re-encoding, no re-compression, no loss of quality. A merged PDF is essentially a container that holds the original pages side by side.

File size and page limits

There is no hard limit, but the whole process happens in browser memory. Practical guidance:

  • Under 50 MB total — instant on any device, including phones.
  • 50–200 MB total — a few seconds on desktop, slower on mobile.
  • Over 200 MB total — may fail on mobile browsers due to memory limits. Desktop usually handles it.
  • Over 500 MB total — may fail even on desktop. Consider compressing individual files first, then merging.

If a merge fails, the most common reason is that one PDF is very large. Try merging in smaller batches and then merging the batches.

  • Monthly reports. Collect January, February and March reports into a Q1 document.

  • Portfolios. Merge design work, writing samples or code documents into one application.
  • Applications. Attach all supporting documents — ID, proof of address, certificates — as one PDF.

Your privacy is protected

Every operation happens in your browser. Files are read into memory, combined, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

The only network request the page makes is for two open-source libraries — pdf-lib for merging and, when needed, Mozilla's pdf.js for previewing. Both are loaded from a public CDN when the page first opens. After that, the tool works entirely offline.

This makes the tool safe for documents you'd never upload to a cloud service: bank statements, medical records, tax returns, contracts, passport scans, and anything covered by an NDA.

What this merger can't do

Being honest about limits is more useful than pretending they don't exist. This merger does not:

  • Split PDFs. Use Split PDF for that.
  • Reorder individual pages. It merges whole files. To rearrange pages inside a PDF, use Organize PDF first.
  • Delete pages from a source file. Use Delete PDF Pages or Organize PDF before merging.
  • Compress the result. The output is roughly the sum of the inputs. To reduce size, use Compress PDF afterwards.
  • Open password-protected PDFs. If a PDF requires a password to open, remove it first with a tool like qpdf. PDFs with only print/edit restrictions usually merge fine.
  • Convert formats. Both inputs and output are PDF. To convert images to PDF, use Image to PDF.

Troubleshooting

  • "PDF library not loaded" — the CDN is blocked or offline. Refresh the page. If it persists, your network may be blocking jsdelivr.net.
  • "Could not read PDF" — the file is likely password-protected, corrupted, or uses an unusual PDF variant. Try opening it in a reader first, or re-export it.
  • Merge is very slow — total file size is probably over 100 MB. Try merging fewer files at once, or compressing each input first.
  • Some pages are missing — check that the source PDFs aren't encrypted or restricted. Also confirm each file's page count in the list before merging.
  • Bookmarks point to wrong pages — bookmarks are offset by pages added before their source. This is correct behaviour but can be confusing if you reorder files after bookmarks were created in the source.
  • Mobile browser crashes — memory limit reached. Merge smaller batches.

Common questions

Is this PDF merger free?

Yes. It is completely free, has no file limit, and does not add watermarks.

Are my PDFs uploaded?

No. Everything happens in your browser. Your files never leave your device.

Can I control the order of pages?

Yes. Drag the files on desktop, or use the up and down arrows on any device. Pages appear in the order you arrange them.

Does it work on mobile?

Yes. Tap the upload box to select files, and use the arrow buttons to reorder them.

Is there a file size limit?

No hard limit, though very large files (100 MB+) may be slow on low-end devices because processing happens in memory.

Will password-protected PDFs work?

Not if they require a password to open. If the password is only for editing or printing, merging usually works.

Does merging reduce quality?

No. Merging copies each page as-is into the new document. There's zero quality loss.

Can I merge PDFs with different page sizes?

Yes. Page sizes don't need to match. The output preserves each page's original size and orientation.

What happens to bookmarks and links?

Internal links and bookmarks are preserved and offset by the pages added before their source PDF.

Can I merge more than 10 PDFs at once?

Yes. There's no fixed cap. Ten to fifty typical PDFs work fine on any modern device. Very large batches may exceed browser memory.

Does it work offline?

Yes. After the page loads once, you can disconnect from the internet and keep merging.

How is this different from Adobe Acrobat?

For merging, nothing — it does the same job. Acrobat offers OCR, form creation, digital signatures and editing, but for combining PDFs this tool matches it for free and without uploading.
