    Delete pages from any PDF — free, in your browser

    This tool removes unwanted pages from a PDF without uploading anything. Scroll through every page in a continuous viewer, click any page to mark it red, and download a clean new file without those pages. Everything runs locally in your browser using JavaScript, so contracts, tax documents, medical records and legal filings never leave your device.

    Unlike most online PDF page removers that upload your file to a server, keep it for hours, watermark the output, or require an account, this tool reads the PDF into memory on your machine, builds a new file with the pages you kept, and offers it as a download. You can disconnect from the internet after the page loads and keep deleting pages.

    How to delete pages from a PDF

    1. Open your PDF. Drop a file onto the drop zone or click to choose one. Every page renders as a preview in the viewer.
    2. Scroll through the pages. The viewer works like a normal PDF reader — every page is stacked vertically. Scroll up and down to review the document.
    3. Click any page to mark it for deletion. A red overlay appears and the page number shows up in the Selected list on the right.
    4. Bulk-select with a range (optional). Type something like 2, 5-8, 12 into the Pages input to mark multiple pages at once. The viewer updates instantly.
    5. Use quick-select buttons (optional). One-click patterns: All, None, Invert, Odd, Even, First 3, Last 3.
    6. Choose your mode. Delete mode removes selected pages. Keep mode keeps selected pages and removes everything else.
    7. Delete and download. Click Delete selected pages. A new PDF is built and offered as a download. Your original file stays untouched on your device.

    Delete mode vs Keep mode

    The Mode toggle at the top of the left panel has two settings. They invert the logic of what you select:

    ModeWhat you selectResult
    DeletePages to removeA new PDF with those pages gone
    KeepPages to keepA new PDF with only those pages — everything else is deleted

    Delete mode is the default. Use it when you're cleaning up a document and only need to drop a few pages.

    Keep mode is faster when you want a small excerpt from a large PDF. Instead of scrolling through 200 pages to mark 197 of them for deletion, you mark the 3 you want to keep and the tool removes the rest in one click.

    Three ways to select pages

    1. Click pages in the viewer

    Click or tap any page directly in the viewer. It gets a red overlay and appears in the Selected list. Click it again to unmark it. This is the most intuitive option for a few pages.

    2. Type a range

    The Pages input accepts several formats:

    • 5 — a single page
    • 2, 4, 6 — a list of pages
    • 5-8 — an inclusive range
    • 1, 3, 10-15, 20 — a mix of the above

    As you type, the viewer updates immediately to show your selection. Invalid input is highlighted in red.

    3. Use the quick-select buttons

    Eight one-click patterns:

    • All — select every page
    • None — deselect everything
    • Invert — flip the current selection
    • Odd — every odd page (1, 3, 5, …)
    • Even — every even page (2, 4, 6, …)
    • First 3 — pages 1, 2, 3
    • Last 3 — the final three pages
    • Blanks — reserved for a future feature that detects blank pages automatically

    How the tool works

    Two open-source JavaScript libraries run entirely in your browser:

    • pdf.js (Mozilla) — parses the PDF and renders each page to a canvas for the viewer. Pages load on-demand as you scroll, so even a 500-page PDF stays fast.
    • pdf-lib — creates the new PDF by copying the pages you kept from the original.

    When you click Delete selected pages, the tool loads the original PDF as a structured object, extracts the pages you kept, and writes them into a new PDF document. Pages are copied byte-for-byte. Fonts, images, vector drawings, hyperlinks, form fields, bookmarks and metadata all carry through unchanged. There is no re-compression and no quality loss.

    Common uses

    • Remove blank pages. Scanned documents often have blank or near-blank pages between sections. Mark them and delete in one pass.
    • Strip cover pages. If you're compiling reports into a single file, remove each individual cover before merging.
    • Remove ads or inserts. Magazine PDFs and downloaded brochures often include advertising pages that don't belong in an archive.
    • Clean up scanned bundles. Bank statements, invoices or receipts often have mis-scanned pages that need to be removed.
    • Extract a section. Use Keep mode to keep only the pages you need and produce a clean excerpt.
    • Split a chapter out. Combine Keep mode with a range like 12-45 to extract a single chapter as a standalone PDF.
    • Remove outdated pages. Legal filings sometimes need old exhibits removed before a new submission.
    • Delete drafts. Manuscript PDFs with leftover draft pages can be cleaned in one pass.
    • Trim product catalogs. Remove discontinued products before sharing with clients.
    • Prepare for upload. Some systems cap uploads at a maximum number of pages — remove the extras before uploading.

    Zoom controls

    The viewer has four ways to zoom:

    • + button — zoom in. Stops automatically when the page reaches the viewer width.
    • − button — zoom out. Minimum is 35% of the original viewer width.
    • Fit — reset to fit the viewer width. This is the default and works best for most documents.
    • Ctrl + scroll wheel (desktop only) — smooth zoom without clicking buttons.

    Zoom is capped so pages never overflow horizontally. The viewer width is a hard limit; pages stay inside it and scroll vertically instead.

    Your privacy is protected

    Every operation happens in your browser. The PDF is read into memory, filtered, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

    The only network requests the page makes are for two open-source libraries — pdf-lib and Mozilla's pdf.js — both loaded from a public CDN when the page first opens. After that, the tool works entirely offline. You can disconnect from the internet and keep deleting pages.

    This makes the tool safe for documents you'd never upload to a cloud service: contracts, medical records, tax returns, bank statements, passport scans, legal filings, signed agreements, personnel records.

    What this tool can't do

    Being honest about limits is more useful than pretending they don't exist. This tool does not:

    • Split into multiple files. Use Split PDF to divide a PDF into several separate files.
    • Merge PDFs. Use Merge PDF for combining files.
    • Reorder pages. Use Organize PDF to change page order.
    • Insert new pages. Use Organize PDF to add blank pages or pages from other files.
    • Auto-detect blank pages. The Blanks quick-select button is reserved for a future feature. For now, select blank pages manually by scrolling through the viewer.
    • Undo a deletion. The tool builds a new PDF and offers it as a download. Your original file stays untouched on your device, so rerun the tool if you need to start over.
    • Edit page content. Use PDF Editor to edit text, add annotations or sign pages.
    • Compress the output. Pages you keep are copied byte-for-byte, so the output is close in size to the sum of the pages kept. Use Compress PDF afterwards.
    • Handle password-protected PDFs. If the PDF requires a password to open, remove it first with a tool like qpdf.

    Troubleshooting

    • "PDF library failed to load" — the CDN is blocked or you're offline before the first page load. Refresh the page once. After that, the tool works offline.
    • Pages render slowly — the PDF is very large. Pages render on-demand as you scroll, so initial load is fast. Scrolling to the end of a 500-page document renders each page as it comes into view.
    • Some pages don't render — the page may have non-standard content. Try refreshing the viewer by clicking Fit. If the page still doesn't render, it may be corrupted in the source PDF.
    • Cannot delete the last remaining page — PDFs must contain at least one page. The tool prevents you from deleting all pages at once.
    • Range input shows red — the syntax is invalid. Check for typos. Valid examples: 5, 2, 4, 6, 5-8, 1, 3, 10-15, 20.
    • Output looks correct but bookmarks are broken — bookmarks that pointed to removed pages are dropped in the new file. Bookmarks to kept pages are preserved.
    • Zoom doesn't go past 100% — the zoom is capped so pages never exceed the viewer width. If the viewer is very wide, this cap is higher. If the viewer is narrow, the cap is lower.
    • Mobile browser crashes on a large PDF — memory limit reached. Try deleting pages in stages using Keep mode to produce a smaller output first.

    Common questions

    Is this PDF page remover free?

    Yes. Completely free, no page limit, no watermarks, no signup.

    Are my PDFs uploaded to a server?

    No. Everything happens in your browser. Your file never leaves your device.

    Can I see all pages at once?

    Yes. The viewer shows every page stacked vertically so you can scroll through the whole document like a normal PDF reader.

    How do I select pages to delete?

    Click or tap any page in the viewer to mark it red. Click again to unmark. You can also type a range like 2, 5-8, 12.

    Can I keep only a few pages instead?

    Yes. Switch the Mode toggle to Keep, select the pages you want to keep, and the tool removes everything else.

    Does deleting pages reduce quality?

    No. Pages you keep are copied byte-for-byte. Fonts, images, vector graphics, links and form fields all carry through unchanged.

    Can I select pages by range?

    Yes. Type ranges like 1, 3, 5-8, 12 into the Pages input. Supported syntax includes single pages, comma-separated lists and hyphen ranges.

    What are the quick-select buttons?

    All, None, Invert, Odd, Even, First 3 and Last 3 provide one-click selection patterns useful for common tasks.

    What is Keep mode?

    Keep mode inverts the logic. Instead of deleting what you select, it keeps what you select and deletes everything else. Useful when you only need a few pages from a large PDF.

    Can I delete every page?

    No. A PDF must contain at least one page. The tool prevents you from deleting all pages at once.

    Does it work on iPhone and Android?

    Yes. The layout stacks into a single column on smaller screens. Tap pages to select them, and use the arrow buttons for quick navigation.

    Can I undo a deletion?

    The tool builds a new PDF and offers it as a download. Your original file remains untouched on your device. If you didn't like the result, run the tool again on the original.

    Can I delete pages from a password-protected PDF?

    Not if the PDF requires a password to open. If it only has print or edit restrictions, the tool may work after removing those restrictions.

    How is this different from Split PDF?

    Split PDF divides a document into multiple files. Delete PDF Pages removes unwanted pages and produces a single output file. Use Split when you want to break a PDF apart; use Delete when you want to clean it up.

    Does it work offline?

    Yes. After the page loads once, the tool works entirely offline. Disconnect from the internet and keep deleting pages.

    How is this different from Adobe Acrobat?

    For deleting pages, nothing — it does the same job. Acrobat offers advanced features like OCR and form creation, but for page removal this tool matches it for free and without uploading.
