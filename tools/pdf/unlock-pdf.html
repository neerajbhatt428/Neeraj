Remove the password from a PDF you own

This tool strips password protection from a PDF and produces a new unlocked file. It's for the common case where you have a document you own — a bank statement, an insurance policy, a tax return, a signed contract — and you're tired of typing the password every time you open it.

Everything runs in your browser using JavaScript. Your PDF is read into memory, decrypted, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

Only for PDFs you have access to

This tool does not crack, guess, brute-force, or bypass passwords. It requires you to already know the password. That's the ethical line, and it's also a practical one: there is no way to open a user-password-protected PDF without the correct password. The encryption is real.

If you don't know the password, contact whoever sent you the file. There is no legitimate tool — in a browser, on a desktop, or anywhere else — that can open a strong encrypted PDF without the password in any reasonable amount of time.

Removing a password from a document you own or have permission to modify is legal in most jurisdictions. Using it on someone else's document without permission is not. Only use this on files you have the right to modify.

Two kinds of PDF password

PDFs can be protected with two different passwords, and they behave very differently:

TypeWhat it doesWhat you need
Owner password File opens freely, but copying, editing or printing is blocked No password. Leave the field blank.
User password File refuses to open at all until you type the password The correct password. Type it in.

Most PDFs that "look locked" to end users are owner-protected. They open fine, but the reader greys out the copy and print buttons. Those are the easiest case — no password required.

User-protected PDFs are rarer. They're used for sensitive documents where the sender wants to control who can even read the file.

How to remove the password

  1. Drop the PDF. Click the drop zone or drag a file onto it.
  2. Leave the password field blank if the PDF opens freely. This covers owner-protected PDFs — the common case.
  3. Type the password if the PDF asks for one to open. This covers user-protected PDFs.
  4. Click Remove password. The tool processes the file in your browser.
  5. Download the unlocked PDF. The file is saved with -unlocked appended to the original filename.

How the tool works

The tool tries two approaches in order:

1. Lossless unlock (owner-password PDFs)

Uses pdf-lib, an open-source JavaScript library, to load the PDF while ignoring its permissions dictionary. It then writes a new PDF without any encryption. This preserves everything: text stays selectable, images keep full quality, form fields survive, hyperlinks work. The output is byte-for-byte the original content, just without the security wrapper.

2. Rasterise-and-rebuild (user-password PDFs)

Uses Mozilla's pdf.js to open the PDF with the password you supplied. It renders each page to a canvas, then rebuilds a new PDF with pdf-lib by embedding each page as a JPEG. The result is visually identical but text is no longer selectable, because the pages are now images. This is the only way to produce an unlocked PDF when the content itself is encrypted.

You don't need to know which path will be used — the tool picks automatically.

Common uses

  • Bank statements. Most banks password-protect PDFs using a known pattern (often your date of birth or account number). Remove it once and archive the unlocked version.
  • Tax documents. Tax portals often lock the file with your Social Security Number or a PIN. Unlock to keep for your records.
  • Insurance policies. Insurers often deliver policies as owner-protected PDFs to prevent editing. Remove the protection for easier access.
  • Signed contracts. Some e-signature platforms lock the final PDF. Unlock to sign additional copies or combine with other documents.
  • Payslips and receipts. Employers and vendors frequently lock these. Unlock for expense reports or accounting.
  • Ebooks and manuals. Some publishers lock their PDFs against copying. If you own the file, you can remove the protection for personal use.
  • Personal archives. If you have dozens of locked PDFs, unlock them once and store them without passwords.
  • Before editing. Many PDF editors refuse to open password-protected files, even owner-protected ones. Unlock first, then edit.

Your privacy is protected

Every operation happens in your browser. The PDF is read into memory, decrypted, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

The only network requests the page makes are for two open-source libraries — pdf-lib and Mozilla's pdf.js — both loaded from a public CDN when the page first opens. After that, the tool works entirely offline. You can disconnect from the internet and keep unlocking.

This makes the tool safe for the most sensitive documents you have: bank statements, tax returns, medical records, ID scans, legal filings, personal correspondence.

What this tool can't do

Being honest about limits is more useful than pretending they don't exist. This tool does not:

  • Crack, guess or brute-force passwords. There is no shortcut. If you don't know the password, this tool cannot open the PDF.
  • Decrypt AES-256 protected PDFs without the password. Modern PDF encryption is real cryptography. Without the key, the content is unreadable.
  • Preserve text in user-password unlocks. The rebuild process converts pages to images, so text becomes non-selectable.
  • Preserve form fields, hyperlinks or bookmarks in user-password unlocks. Same reason — the pages become flat images.
  • Remove DRM from Adobe Digital Editions files. Those use a different system with account-based DRM. This tool doesn't touch them.
  • Unlock PDFs protected by server-side systems. Some corporate PDFs use certificate-based encryption that ties access to a specific user account. Those can't be unlocked in a browser.
  • Handle very large PDFs. Files over 200 MB are unreliable in a browser due to memory limits.

Troubleshooting

  • "This PDF requires a password to open" — the file has a user password and the password field is empty. Type the password and try again.
  • "Incorrect password" — the password doesn't match. Check for typos, case sensitivity, or leading/trailing spaces. Some banks send the password in a separate email.
  • Owner-protected unlock fails — some PDFs use non-standard encryption wrappers. Try providing the owner password if you have it, or use a desktop tool like qpdf.
  • Text disappeared after unlocking — that's expected for user-password unlocks. The pages are rebuilt as images. If you need selectable text, run OCR on the unlocked file afterwards.
  • File size grew after unlocking — also expected for user-password unlocks, because pages become images. Run the result through Compress PDF to bring it back down.
  • "PDF library not loaded" — the CDN is blocked or you're offline before the first page load. Refresh the page once. After that, the tool works offline.
  • Very large PDF takes a long time — user-password unlock rasterizes every page, which is CPU-heavy. On a large PDF, expect 30–90 seconds.
  • Mobile browser crashes — memory limit reached. Try unlocking on a desktop browser, or use a smaller PDF.

Common questions

Can I unlock a PDF without knowing the password?

No. This tool removes the password from a PDF you already have access to. It does not crack, guess or brute-force passwords. If you don't know the password, you need to get it from whoever sent you the file.

What is the difference between an owner password and a user password?

An owner password lets you open the file but blocks copying, editing or printing. A user password blocks opening the file entirely until you enter it. This tool handles both, but requires the user password if the PDF has one.

Will the text stay selectable after unlocking?

Yes, if the PDF has an owner password only. If the PDF requires a user password, the unlocked version is rebuilt by rendering each page as an image, so text becomes non-selectable.

Are my PDFs uploaded?

No. Everything happens in your browser. Your PDF never leaves your device.

Is this legal?

Removing a password from a document you own or have permission to modify is legal in most jurisdictions. Using it on someone else's document without permission is not. Only use this on files you have the right to modify.

Does it work on iPhone and Android?

Yes. Tap the drop zone to select a PDF from Files or Downloads, enter the password if needed, and download the unlocked file directly to your device.

Can I unlock multiple PDFs at once?

Not currently. Unlock one file at a time.

What happens if I enter the wrong password?

The tool tells you the password is incorrect and doesn't produce an output file. Nothing is saved or sent anywhere.

Does it work offline?

Yes. After the page loads once, the tool works entirely offline.

What format does the unlocked PDF have?

A standard unencrypted PDF that opens in any reader without a password. Owner-password PDFs keep their original text, images, links and form fields. User-password PDFs are rebuilt as image-based pages.
