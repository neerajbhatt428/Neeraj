Remove the password from a PDF you own

This tool strips password protection from a PDF and produces a new unlocked file. It's for the common case where you have a document you own — a bank statement, an insurance policy, a tax return, a signed contract — and you're tired of typing the password every time you open it.

Everything runs in your browser using WebAssembly. Your PDF is read into memory, decrypted, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

Lossless — not just a rasterised copy

Most browser-based PDF unlockers work by rendering each page as an image, then assembling those images into a new PDF. The result looks the same but is fundamentally different: text is no longer selectable, links are gone, and a 4 KB text PDF becomes a 200 KB image file.

This tool takes a different approach. It uses qpdf compiled to WebAssembly — the same C++ library that powers many desktop PDF tools — to decrypt the PDF's content streams in place. The output is a genuine unencrypted PDF with everything preserved:

  • Selectable and searchable text
  • Vector graphics and scalable diagrams
  • Embedded images at full original quality
  • Hyperlinks and internal navigation
  • Bookmarks and outlines
  • Form fields and annotations

The output file size stays close to the original — usually the same, sometimes smaller, because the removed encryption dictionary had overhead of its own.

Only for PDFs you have access to

This tool does not crack, guess, brute-force, or bypass passwords. It requires you to already know the password. That's the ethical line, and it's also a practical one: there is no way to open a user-password-protected PDF without the correct password. The encryption is real.

If you don't know the password, contact whoever sent you the file. There is no legitimate tool — in a browser, on a desktop, or anywhere else — that can open a strong encrypted PDF without the password in any reasonable amount of time.

Removing a password from a document you own or have permission to modify is legal in most jurisdictions. Using it on someone else's document without permission is not. Only use this on files you have the right to modify.

Two kinds of PDF password

PDFs can be protected with two different passwords, and they behave very differently:

TypeWhat it doesWhat you need
Owner password File opens freely, but copying, editing or printing is blocked No password. Leave the field blank.
User password File refuses to open at all until you type the password The correct password. Type it in.

Most PDFs that "look locked" to end users are owner-protected. They open fine, but the reader greys out the copy and print buttons. Those are the easiest case — no password required.

How to remove the password

  1. Drop the PDF. Click the drop zone or drag a file onto it.
  2. Leave the password field blank if the PDF opens freely. This covers owner-protected PDFs.
  3. Type the password if the PDF asks for one to open. This covers user-protected PDFs.
  4. Click Remove password. The tool decrypts the file in your browser.
  5. Download the unlocked PDF. The file is saved with -unlocked appended to the original filename.

How the tool works

PDF encryption is real cryptography. The content streams inside a password-protected PDF are encrypted with a key derived from the password. To produce an unlocked PDF, the tool has to decrypt those streams.

The tool uses qpdf compiled to WebAssembly. qpdf is a command-line tool used by archivists, libraries and law firms for PDF transformations, and its encryption code is well-audited. When you click Remove password:

  1. The PDF is loaded into memory in your browser.
  2. If the PDF has a user password, qpdf authenticates using the password you typed.
  3. qpdf decrypts every content stream using the key derived from the password.
  4. qpdf writes a new PDF with no encryption dictionary, using object stream compression for efficiency.
  5. The result downloads with all text, links, forms and images intact.

If qpdf can't process the file for any reason — an unusual encryption scheme, a corrupted source, a format it doesn't recognise — the tool automatically falls back to a rasterise mode that renders each page as an image. The fallback produces a larger file and loses selectable text, but it handles almost any PDF that can be opened at all.

Why file size matters

A common complaint about browser-based PDF unlockers is that the output is much larger than the input. That happens because those tools render every page as an image. A 4 KB text-only PDF becomes a 200–500 KB image PDF because a JPEG of a page is inherently larger than the same page stored as compact character codes.

This tool avoids that problem entirely. Because the content is decrypted in place, the output is essentially the same file with the encryption layer stripped. If your source is 4 KB, your output is 3–5 KB. If your source is 4 MB, your output is 4 MB. There is no size penalty for using lossless unlock.

Common uses

  • Bank statements. Most banks password-protect PDFs using a known pattern. Remove it once and archive the unlocked version.
  • Tax documents. Tax portals often lock the file with your Social Security Number or a PIN. Unlock to keep for your records.
  • Insurance policies. Insurers often deliver policies as owner-protected PDFs. Remove the protection for easier access.
  • Signed contracts. Some e-signature platforms lock the final PDF. Unlock to sign additional copies or combine with other documents.
  • Payslips and receipts. Employers and vendors frequently lock these. Unlock for expense reports or accounting.
  • Before editing. Many PDF editors refuse to open password-protected files, even owner-protected ones. Unlock first, then edit.

Your privacy is protected

Every operation happens in your browser. The PDF is read into memory, decrypted, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

The only network requests the page makes are for the WebAssembly library and the fonts. Both are loaded from your own site and public CDNs when the page first opens. After that, the tool works entirely offline.

This makes the tool safe for the most sensitive documents you have: bank statements, tax returns, medical records, ID scans, legal filings, personal correspondence.

What this tool can't do

Being honest about limits is more useful than pretending they don't exist. This tool does not:

  • Crack, guess or brute-force passwords. If you don't know the password, this tool cannot open the PDF.
  • Remove DRM from Adobe Digital Editions files. Those use a different system with account-based DRM.
  • Unlock PDFs protected by certificate-based encryption. Some corporate PDFs tie access to a specific user account. Those can't be unlocked in a browser.
  • Handle every unusual PDF. If the lossless engine fails, the tool falls back to rasterize mode. The fallback produces a larger, image-only PDF but handles almost every file that can be opened at all.
  • Remove password restrictions on files you don't own. The tool doesn't check ownership, but using it on someone else's document without permission is likely illegal in your jurisdiction.

Troubleshooting

  • "Incorrect password" — the password doesn't match. Check for typos, case sensitivity, or leading/trailing spaces. Some banks send the password in a separate email.
  • "This PDF requires a password to open" — the file has a user password and the password field is empty. Type the password and try again.
  • Unlock produces a bigger file — the lossless engine failed and the fallback kicked in. The result card shows which mode was used. The fallback is only triggered for unusual PDFs that qpdf can't process.
  • "PDF library not loaded" — a CDN is blocked or you're offline before the first page load. Refresh the page once. After that, the tool works offline.
  • Mobile browser crashes — memory limit reached with a very large PDF. Try unlocking on a desktop browser.
  • Text disappeared from the unlocked PDF — this means the fallback rasterizer was used, which strips the text layer. Check the result note to see which mode ran.

Common questions

Can I unlock a PDF without knowing the password?

No. This tool removes the password from a PDF you already have access to. It does not crack, guess or brute-force passwords.

What is the difference between an owner password and a user password?

An owner password lets you open the file but blocks copying, editing or printing. A user password blocks opening the file entirely until you enter it. This tool handles both, but requires the user password if the PDF has one.

Will the text stay selectable after unlocking?

Yes. The unlock is lossless. Text, vector graphics, form fields, hyperlinks and bookmarks are all preserved exactly as they were in the original. The output is a genuine unencrypted PDF, not a set of rendered images.

Does the unlocked PDF lose quality?

No. There is no re-encoding and no rasterization. The content streams are decrypted in place and written to a new unencrypted PDF. The output is byte-for-byte identical in content to the original, minus the encryption layer.

Will the output file be the same size?

Yes, or smaller. Because encryption dictionaries add overhead, the unlocked file is usually the same size or a few percent smaller. A 4 KB locked PDF typically unlocks to a 3-4 KB file.

Are my PDFs uploaded?

No. Everything happens in your browser. Your PDF never leaves your device.

Is this legal?

Removing a password from a document you own or have permission to modify is legal in most jurisdictions. Using it on someone else's document without permission is not. Only use this on files you have the right to modify.

Does it work on iPhone and Android?

Yes. Tap the drop zone to select a PDF from Files or Downloads, enter the password if needed, and download the unlocked file directly to your device.

What happens if I enter the wrong password?

The tool shows an incorrect password message and does not produce an output file.

Does it work offline?

Yes. After the page loads once, the tool works entirely offline.

What if the lossless engine fails on my PDF?

The tool falls back to a rasterise mode that renders every page as a high-resolution image. This handles almost every unusual PDF but produces a larger output file and loses selectable text.

What format does the unlocked PDF have?

A standard unencrypted PDF that opens in any reader without a password. Text stays selectable, links keep working, form fields stay editable.
