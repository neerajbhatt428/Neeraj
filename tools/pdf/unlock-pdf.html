Remove the password from a PDF you own

This tool strips password protection from a PDF and produces a new unlocked file. It's for the common case where you have a document you own — a bank statement, an insurance policy, a tax return, a signed contract — and you're tired of typing the password every time you open it.

Everything runs in your browser using JavaScript. Your PDF is read into memory, decrypted, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

Only for PDFs you have access to

This tool does not crack, guess, brute-force, or bypass passwords. It requires you to already know the password. That's the ethical line, and it's also a practical one: there is no way to open a user-password-protected PDF without the correct password. The encryption is real.

If you don't know the password, contact whoever sent you the file. There is no legitimate tool — in a browser, on a desktop, or anywhere else — that can open a strong encrypted PDF without the password in any reasonable amount of time.

Removing a password from a document you own or have permission to modify is legal in most jurisdictions. Using it on someone else's document without permission is not. Only use this on files you have the right to modify.

Two kinds of PDF password

PDFs can be protected with two different passwords, and they behave very differently:

TypeWhat it doesWhat you need
Owner password File opens freely, but copying, editing or printing is blocked No password. Leave the field blank.
User password File refuses to open at all until you type the password The correct password. Type it in.

Most PDFs that "look locked" to end users are owner-protected. They open fine, but the reader greys out the copy and print buttons. Those are the easiest case — no password required.

How to remove the password

  1. Drop the PDF. Click the drop zone or drag a file onto it.
  2. Leave the password field blank if the PDF opens freely. This covers owner-protected PDFs.
  3. Type the password if the PDF asks for one to open. This covers user-protected PDFs.
  4. Pick an output quality. High is the default and is right for almost every use case.
  5. Click Remove password. The tool processes the file in your browser.
  6. Download the unlocked PDF. The file is saved with -unlocked appended to the original filename.

Use Maximum for documents you plan to print at high resolution, for archival purposes, or if the source contains a lot of fine detail like architectural drawings or dense tables.

Use Standard when file size matters more than fidelity — for example, when attaching to email with a strict size cap.

How the tool works

PDF encryption is real cryptography. The content streams inside a password-protected PDF are encrypted with a key derived from the password. To produce an unlocked PDF, the tool has to decrypt those streams first.

The only library that can properly decrypt a PDF in a browser is Mozilla's pdf.js — the same engine Firefox uses. It's a viewer, not an editor. It exposes decrypted page content through a rendering API but has no "export to PDF" method.

So the tool does this:

  1. Opens the PDF with pdf.js, using your password (or a blank password for owner-only PDFs).
  2. Renders each page to a canvas at your chosen DPI, using the print rendering intent for sharper text and vector graphics than the default display path.
  3. Encodes each page as a JPEG at high quality.
  4. Assembles a new PDF with pdf-lib by embedding each JPEG at the original page dimensions.
  5. Downloads the result — an unencrypted PDF that opens in any reader without a password.

Because pages are images, text is not selectable and form fields are not preserved. The visual output matches the original at normal reading zoom. That's the trade-off for producing a genuinely unencrypted PDF entirely in a browser.

Why browsers can't do lossless unlock

Desktop tools like qpdf or MuPDF can decrypt PDF content streams and re-encode them into a new file with no protection — keeping text selectable and all vector data intact. That is genuinely lossless.

No JavaScript library in a browser does this today. Every browser-based PDF unlocker — including the ones that don't tell you — rasterizes pages. The only way to get lossless unlock online is to use a service that runs decryption on a server, which means your PDF is uploaded to that server.

This tool chooses not to do that. Rasterizing in the browser keeps the file on your device, at the cost of losing the text layer. If selectable text is essential, unlock with a desktop tool like qpdf — it's free, open-source, and runs offline.

Common uses

  • Bank statements. Most banks password-protect PDFs using a known pattern. Remove it once and archive the unlocked version.
  • Tax documents. Tax portals often lock the file with your Social Security Number or a PIN. Unlock to keep for your records.
  • Insurance policies. Insurers often deliver policies as owner-protected PDFs. Remove the protection for easier access.
  • Signed contracts. Some e-signature platforms lock the final PDF. Unlock to sign additional copies or combine with other documents.
  • Payslips and receipts. Employers and vendors frequently lock these. Unlock for expense reports or accounting.
  • Before editing. Many PDF editors refuse to open password-protected files, even owner-protected ones. Unlock first, then edit.

Your privacy is protected

Every operation happens in your browser. The PDF is read into memory, decrypted, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

The only network requests the page makes are for two open-source libraries — pdf-lib and Mozilla's pdf.js — both loaded from a public CDN when the page first opens. After that, the tool works entirely offline.

This makes the tool safe for the most sensitive documents you have: bank statements, tax returns, medical records, ID scans, legal filings, personal correspondence.

What this tool can't do

Being honest about limits is more useful than pretending they don't exist. This tool does not:

  • Crack, guess or brute-force passwords. If you don't know the password, this tool cannot open the PDF.
  • Preserve selectable text. The output is a new PDF where each page is a high-resolution image. Text cannot be selected or searched. To recover text, run OCR on the unlocked file.
  • Preserve form fields, hyperlinks or bookmarks. Same reason — the pages become images.
  • Remove DRM from Adobe Digital Editions files. Those use a different system with account-based DRM.
  • Unlock PDFs protected by certificate-based encryption. Some corporate PDFs tie access to a specific user account. Those can't be unlocked in a browser.
  • Handle very large PDFs. Files over 200 MB are unreliable in a browser due to memory limits.

Troubleshooting

  • "Incorrect password" — the password doesn't match. Check for typos, case sensitivity, or leading/trailing spaces. Some banks send the password in a separate email.
  • "This PDF requires a password to open" — the file has a user password and the password field is empty. Type the password and try again.
  • Unlock takes a long time — every page must be rendered and re-encoded. On a 100-page PDF at Maximum quality, expect 60–120 seconds.
  • File size grew a lot after unlocking — expected, because pages become high-resolution images. Try a lower quality preset, or run the result through Compress PDF.
  • Text disappeared from the unlocked PDF — the visual content is preserved, but text is now part of an image and cannot be selected. This is the trade-off for producing an unencrypted PDF in a browser.
  • "PDF library not loaded" — the CDN is blocked or you're offline before the first page load. Refresh the page once. After that, the tool works offline.
  • Mobile browser crashes — memory limit reached. Try a lower quality preset, or unlock on a desktop browser.

Common questions

Can I unlock a PDF without knowing the password?

No. This tool removes the password from a PDF you already have access to. It does not crack, guess or brute-force passwords.

What is the difference between an owner password and a user password?

An owner password lets you open the file but blocks copying, editing or printing. A user password blocks opening the file entirely until you enter it. This tool handles both, but requires the user password if the PDF has one.

Will the text stay selectable after unlocking?

No. This tool rebuilds encrypted PDFs by rendering every page as a high-resolution image and assembling them into a new PDF. The output opens without a password and looks identical at normal zoom, but text is not selectable, and form fields or hyperlinks are not preserved.

Does the unlocked PDF lose quality?

At the default High quality setting, the output renders at 220 DPI with print-quality rendering intent and near-lossless JPEG encoding. Zoomed to 200 percent, it is visually indistinguishable from the original. Only at extreme zoom (400 percent and above) will you see pixelation where a truly lossless unlock would show crisp vector text.

What quality setting should I use?

High is the default and matches the visual quality of most desktop PDF viewers at normal reading zoom. Use Maximum for documents you plan to print at high resolution or archive long-term. Use Standard for quick sharing where file size matters more than fidelity.

Are my PDFs uploaded?

No. Everything happens in your browser. Your PDF never leaves your device.

Is this legal?

Removing a password from a document you own or have permission to modify is legal in most jurisdictions. Using it on someone else's document without permission is not. Only use this on files you have the right to modify.

Does it work on iPhone and Android?

Yes. Tap the drop zone to select a PDF from Files or Downloads, enter the password if needed, and download the unlocked file directly to your device.

What happens if I enter the wrong password?

The tool shows an incorrect password message and does not produce an output file.

Does it work offline?

Yes. After the page loads once, the tool works entirely offline.

What format does the unlocked PDF have?

A standard unencrypted PDF that opens in any reader without a password. Pages are rendered as high-resolution images, so text is not selectable but the visual appearance matches the original.
