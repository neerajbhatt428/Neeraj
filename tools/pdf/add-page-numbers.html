Add page numbers to any PDF — free, in your browser

This tool adds page numbers to every page of a PDF without uploading anything. Choose where the numbers appear, what format they use, what number to start from, and how they look. Everything runs locally in your browser using JavaScript, so contracts, tax documents, medical records and legal filings never leave your device.

Unlike most online PDF numbering tools that upload your file to a server, keep it for hours, watermark the output, or require an account, this tool reads the PDF into memory on your machine, draws the numbers, and saves the result. You can disconnect from the internet after the page loads and keep working.

How to add page numbers to a PDF

  1. Open the PDF. Drop a file onto the drop zone or click to choose one. Page count and file size display automatically.
  2. Choose position. Click one of the six position cells — top-left, top-center, top-right, bottom-left, bottom-center or bottom-right. Bottom-center is the default and matches most printed documents.
  3. Choose format. Pick from 1, 1 / 10, Page 1 or Page 1 of 10.
  4. Set starting number (optional). If the PDF is a chapter of a larger document, change Start at to match. For example, if chapter 3 begins on page 45, set Start at to 45.
  5. Skip the cover page (optional). Enable Skip first page if your PDF starts with a cover, title page or table of contents you don't want numbered.
  6. Adjust appearance. Set font size, margin and text color. Defaults look good for most documents.
  7. Apply and download. Click Add page numbers & download. The new PDF saves to your device with -numbered appended to the filename.

Which number format should you use?

Each format has a specific purpose. Picking the right one matters for professional documents:

FormatExampleBest for
1, 2, 31Casual documents, internal reports, anything where total length isn't needed
1 / 101 / 10Legal submissions, academic papers, patent applications where total length matters
Page 1Page 1Formal reports, proposals, anything where "1" alone looks too minimal
Page 1 of 10Page 1 of 10Contracts, manuals, instruction books — the most explicit format

If you're unsure, Page 1 of 10 is the safest choice. It's what most contracts and legal documents use.

When to skip the first page

Most professional documents have a cover page that shouldn't be numbered — a title page, a table of contents, or a cover letter stapled to the front of a report. The Skip first page option leaves the first page untouched and starts numbering on page two.

Importantly, the total count still reflects the whole document. A 10-page PDF with skip enabled shows Page 2 of 10 on the second page and Page 10 of 10 on the last. The skipped page counts toward the total, so page numbers stay accurate.

If you need to skip more than one page, run the tool twice — once to number pages 1 through N, then a second time on the output to remove numbers from any pages you don't want (not currently supported), or use Organize PDF to split the document first.

How the numbering works

The tool uses pdf-lib, an open-source JavaScript library that runs in your browser. When you click Apply, it:

  1. Loads the PDF into memory as a structured object.
  2. Embeds Helvetica as the numbering font — a standard PDF font available in every reader.
  3. Iterates through every page, computing the number and its position based on your settings.
  4. Draws the number as real text on each page using drawText().
  5. Serialises the result to a new PDF and hands you a download link.

The numbers you add are real PDF text objects, not images. That means they're searchable, selectable and copyable — the same as any other text in the document. They stay sharp at any zoom level and don't add meaningful file size.

Common uses

  • Legal filings. Courts often require sequential page numbers on every page of a filing — sometimes with "of N" totals. Use Page 1 of 10 and skip the caption page.
  • Academic theses. Universities frequently require specific formats — often with a skip on the title page and roman numerals for front matter, or Arabic numerals starting from the first chapter.
  • Manuals and instruction books. Page numbers help users reference specific sections.
  • Contracts. Sequential numbering prevents pages from being removed or inserted without detection.
  • Reports for clients. Page numbers give a professional touch and make review easier.
  • Printed board packs. When board members print a 100-page pack, page numbers help them follow along.
  • Proofreading. Numbered pages make it easier to reference corrections.
  • Compliance documents. Some industries require paginated PDFs for audit trails.
  • Books and manuscripts. Standard page numbering for print or e-reader conversion.

Your privacy is protected

Every operation happens in your browser. The PDF is read into memory, modified, and written back to disk by your own device. No PDF is ever sent to any server, logged, or retained.

The only network request the page makes is for the pdf-lib library, loaded from a public CDN when the page first opens. After that, the tool works entirely offline. You can disconnect from the internet and keep numbering.

This makes the tool safe for documents you'd never upload to a cloud service: contracts, medical records, tax returns, bank statements, legal filings, signed agreements, sensitive reports.

What this tool can't do

Being honest about limits is more useful than pretending they don't exist. This tool does not:

  • Use custom fonts. The numbers are drawn in Helvetica, a standard PDF font available in every reader. Custom fonts would need to be embedded, which increases file size and requires the user to supply font files.
  • Skip more than one page. The Skip first page option handles one page. For more complex numbering (roman numerals for front matter, then Arabic numerals for chapters), split the document first with Split PDF and number each part separately.
  • Add numbers to specific pages only. Numbering applies uniformly to all pages (minus the first if skipped).
  • Handle password-protected PDFs. If the PDF requires a password to open, remove it first. PDFs with only print or edit restrictions usually work after removing those restrictions.
  • Undo numbering. Once the numbers are drawn, they're part of the PDF content. Rerun the tool with different settings if needed, or use a PDF editor to remove them.
  • Insert new pages. Use Organize PDF to add blank pages before numbering.

Troubleshooting

  • "PDF library did not load" — the CDN is blocked or you're offline before the first page load. Refresh the page once. After that, the tool works offline.
  • "This PDF is password-protected" — the file requires a password to open. Remove the password with a tool like qpdf, then try again.
  • "Could not open this PDF" — the file is corrupted, or uses a non-standard PDF variant. Open it in a PDF reader first to confirm it displays correctly.
  • Numbering is very slow — the PDF is over 500 pages. Wait a moment. The progress bar shows how far along it is.
  • Numbers overlap existing content — increase the margin setting. The default 28 pt is fine for most documents, but pages with content near the edge may need 40 or 50 pt.
  • Numbers are too small or too large — adjust the font size. 11 pt is standard for body text, 9 pt for dense documents, 14 pt for presentations.
  • Numbers appear in the wrong place — verify the position setting. Bottom-center is standard, but some documents require top-right or bottom-right.
  • Download didn't start — some browsers block downloads if the file is very large. Check your browser's download settings.

Common questions

Is this tool free?

Yes. It is completely free, has no page limit and runs entirely in your browser.

Does my PDF get uploaded?

No. The file is read and rewritten entirely inside your browser using JavaScript. Nothing is sent to any server.

Can I skip the first page?

Yes. Enable the Skip first page option to leave the cover page unnumbered.

What number formats are supported?

Plain (1, 2, 3), of total (1 / 10), labeled (Page 1), and labeled with total (Page 1 of 10).

Will the numbers be selectable text?

Yes. Numbers are added as real text, not an image, so they can be selected, copied and searched.

Can I use a custom font?

Not currently. The tool uses one of the standard PDF fonts, which is available in every PDF reader. Custom fonts would increase the output file size significantly.

What happens to my original PDF?

It stays untouched on your device. The tool creates a new file with the suffix -numbered added to the filename.

Does it work on phones?

Yes. It runs in Safari on iOS and Chrome on Android. Very large PDFs may be slower on older phones.

Can I start numbering from a number other than 1?

Yes. Change the Start at field to any number. Useful when the PDF is a chapter of a larger document.

Does the tool change the page count?

No. The tool only draws text on existing pages. Your page count, page size and page order stay exactly the same.

Can I add page numbers to a password-protected PDF?

Not if the PDF requires a password to open. If it only has print or edit restrictions, numbering usually works after removing those restrictions.

Will the numbers show up when I print?

Yes. Numbers are drawn as real text inside the PDF, so they appear on screen, on print, and in any PDF reader.

Can I use a different font?

The tool uses Helvetica. Custom fonts would need to be embedded, which increases file size and requires uploading font files.

Does it work offline?

Yes. After the page loads once, the tool works entirely offline. Disconnect from the internet and keep numbering.

How is this different from Adobe Acrobat?

For adding page numbers, nothing — it does the same job. Acrobat offers advanced features like OCR and form creation, but for page numbering this tool matches it for free and without uploading.
